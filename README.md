# Exodus Fleet

A real-time space strategy game for the browser, in the style of Homeworld.

**[Play](https://aeromax.github.io/exodus-fleet/)**

## Controls

- Left click / drag: select
- Right click: move, attack or harvest
- Right drag: orbit camera; wheel: zoom
- M, then Shift: move with altitude
- F / Home: focus selection
- Space: sensors manager
- Ctrl+1–9: assign groups
- H / S / P: harvest / stop / pause
